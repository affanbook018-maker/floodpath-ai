How it works & limits
  1. Roads and candidate shelters (schools, hospitals, community centres…) come live from OpenStreetMap.
  2. Each road segment is checked against the flood layer → dry, unverified or flooded.
  3. Dijkstra routing: flooded roads cost ×40, unverified ×2.5, so routes avoid water but still return a clearly labelled “least bad” option if none exists.
  4. Every route carries an honest confidence label — we never claim a path is safe when the data can't prove it.

Demo disclaimer: flood extents in the built-in scenarios are illustrative. Import an official flood mask (NASA Disasters, UNOSAT, Copernicus EMS, Sentinel-1) for real events. Not for real emergency navigation.
